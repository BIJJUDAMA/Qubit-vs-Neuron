\section{Models}
\subsection{Quantum neural network}
The QNN is a two-qubit variational circuit with data re-uploading. A layer first applies $R_y(x_0)$ and $R_y(x_1)$ to encode the two features, then trainable rotations $R_y(\theta_{\ell,0})$ and $R_y(\theta_{\ell,1})$. In the entangled model, a CNOT gate follows, with qubit 0 as control and qubit 1 as target. This layer repeats $L$ times. The primary model uses $L=2$; depths 1 and 3 are also tested.

For the $\ell$th layer, the operation is
\begin{equation}
U_\ell(x,\theta_\ell)=\operatorname{CNOT}_{0\rightarrow1}
\left[R_y(\theta_{\ell,0})\otimes R_y(\theta_{\ell,1})\right]
\left[R_y(x_0)\otimes R_y(x_1)\right],
\end{equation}
where the CNOT is omitted for the no-entanglement ablation. The final state is $|\psi(x,\theta)\rangle=U_L\cdots U_1|00\rangle$. The quantum circuit returns two expectation values, $\langle Z_0\rangle$ and $\langle Z_1\rangle$. A trainable classical linear readout combines them into a logit, which is converted to a positive-class probability using the sigmoid function.

Let $h(x,\theta)=[\langle Z_0\rangle,\langle Z_1\rangle]^\top$ denote the two measured features. The classical readout computes $s=w^\top h+b$ and $p(y=1\mid x)=\sigma(s)$, where $\sigma(s)=1/(1+e^{-s})$. For a labelled training set $\{(x_i,y_i)\}_{i=1}^N$, the objective is binary cross-entropy:
\begin{equation}
  \mathcal{L}(w,b,\theta)=-\frac{1}{N}\sum_{i=1}^{N}\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
\end{equation}
This makes the training loop hybrid: the QNode computes expectation values, PyTorch applies the linear readout and loss, and automatic differentiation propagates gradients through both components. The primary PennyLane implementation executes an analytic \texttt{default.qubit} device using simulator backpropagation. A separate PyTorch statevector reference implementation is maintained for independent numerical and gradient parity tests. Neither mode models the cost of running a gradient on physical hardware.

\subsection{Classical baseline}
The classical model is a PyTorch MLP with architecture $2\rightarrow16\rightarrow8\rightarrow1$, ReLU activations between hidden layers, and a single binary logit at the output. It has 193 trainable parameters. To add a closer parameter-count control, we also use a compact $2\rightarrow2\rightarrow1$ MLP with 9 parameters. The depth-2 QNN has four trainable quantum rotation angles and three trainable readout parameters, for seven trainable parameters in total. These counts are only rough controls: parameter count does not directly measure effective model capacity or the computation used by a model.

\subsection{Optimization}
Both models use full-batch Adam optimization and binary cross-entropy with logits for 100 epochs. The MLP learning rate is 0.01; the QNN learning rate is 0.025. Weight decay is $10^{-4}$ and gradients are clipped to a maximum norm of 5. The different fixed learning rates reflect the different parameterizations; no exhaustive hyperparameter search was conducted. The primary experiment uses exact analytic expectation values during training.
